# Jack — 3D Creator

A dark editorial portfolio landing page for a 3D creator, built around an oversized type-led hero, a scroll-driven gallery marquee, character-reveal biography, five services, and sticky stacked project cards.

## Run locally

```bash
npm ci
npm run dev
npm run build
```

**Stack:** React 18, TypeScript, Vite, Tailwind CSS v3, Framer Motion, and Lucide React. The Vite base is relative so the template publishes at `/jack/` on GitHub Pages.

The portrait, decorative 3D cutouts, project-preview GIFs, and project images use the exact external URLs from the design brief. They are hot-linked rather than downloaded. See the root [`ASSETS.md`](../ASSETS.md) for provenance notes; check remote availability and reuse rights before deployment.
