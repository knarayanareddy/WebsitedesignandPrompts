A pixel-faithful, 1:1 value-for-value replication of [HUMAN.md](https://www.human-md.ai/) by **Briana (Mazzio) May** — *a working manifesto. notes-to-self, mostly. A reminder, in plain text, of what humans actually bring to the table now that the machines are very good and getting better every day.*

Built with **Vite 6.4 + TypeScript + Tailwind CSS 3.4 + Lenis smooth scrolling + GSAP timeline orchestration + custom animated SVG physics mechanisms**. Fully self-contained with all 1,263 visual cutouts, typography assets, and ambient textures preserved locally. GitHub Pages ready (`base: './'`).

## 🎮 Interactive HUD & Controls

1. **The Ceramic Eye-Mug (`.hud-mug`)**:
   - Sculpted ceramic mug icon in top-left navigation.
   - Houses an interactive eyeball pupil that tracks the user's mouse pointer across the screen via trigonometric arc tangent (`Math.atan2`).
   - Clicking the mug triggers an immediate smooth camera return to `#home` at the very beginning of the film.
2. **Document Status Pill (`.hud-file`)**:
   - Displays `HUMAN.md` with an active pulsing orange indicator dot (`#fc4109`).
3. **Dynamic Breadcrumbs (`.hud-crumb`)**:
   - Updates in real-time as the reader scrolls through chapters (`#cover` → `## what this file is` → `## the actual (human) job` → `### 1. break the rule`...).
4. **Cinematic "Watch" Mode (`.hud-watch`)**:
   - Toggles automated, hands-free film playback (`html.is-conducted`).
   - Automatically glides through scroll timelines, triggers animations, and manages pacing while transforming the button into a `"scroll"` interrupt control.
5. **Chapter Tarot Index Drawer (`.hud-index`)**:
   - Toggles a full-screen modal catalog featuring **16 playing/tarot cards**.
   - Each card features an archival cutout, slight organic rotation angle (`--a: 1.42deg`), tinted room theme (`--room: #aebf76`), and quick-jump anchor link to every section.
6. **Mobile Landscape Guard (`.upright`)**:
   - Enforces vertical portrait orientation on mobile devices with an editorial warning screen (*"this one plays upright"*), showing Briana standing on the floor.

## 🎨 Design System & Aesthetics

- **Visual Language**: Surrealist editorial collage meets Terry Gilliam-esque cutouts and Renaissance still life painting.
- **Typography**:
  - Headings / Display: `Bricolage Grotesque` (high-impact contemporary sans-serif)
  - Editorial Accents: `Instrument Serif` (classical, italic serif elegance)
  - Code & Manifesto Notes: `Cutive Mono` (typewriter monospace)
- **Palette**:
  - Canvas: `#201e1f` (deep warm graphite black)
  - Cobalt Room: `#1a37c9` (saturated Klein ultramarine blue)
  - Accent / Laser: `#fc4109` (high-visibility safety orange)
  - Pastoral Green: `#aebf76` (olive green)
  - Pastel Pink: `#f4dada` / `#e8a598`
  - Cellar Earth: `#2b0b02` / `#5a2510`
- **Surface Texture**: Full-bleed procedural SVG `#grain` overlay rendering 35% opacity analog film noise.

## 🎯 Exactness Contract

- **Zero Missing Assets**: All 1,263 webp cutouts, custom SVG filters, and webfonts are self-contained in `public/assets/`.
- **Pure Relative Paths**: Configured with Vite `base: './'` so the deployment functions on any subpath or static host.
- **Semantic & Accessible**: Complete Markdown text contained in `<article id="read" class="read">` for screen readers and reduced-motion environments.
- **Strict Linting & Type Safety**: Passes `tsc --noEmit` with zero errors and `oxlint` with zero warnings.
