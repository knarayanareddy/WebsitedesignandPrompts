# Soda — reference-led rebuild, version 02

**Status: local review preview, not deployed to the published collection.**

This is the replacement-quality pilot requested after the first set of websites was rejected for visual fidelity. It is a dedicated single-screen implementation based on inspected frames from the actual GetLayers Soda video, not the previous shared landing-page generator.

## Open the preview

From the repository root:

```sh
python3 getlayersai/tools/serve.py --port 8080 --entry /getlayersai/rebuilds/soda/
```

Then open `http://localhost:8080/`. The existing collection is still available at `/getlayersai/`. Browser-facing code uses relative URLs only; the localhost URL above is for local development, not an application API.

## What changed

- Restored the single-screen emerald composition rather than a pink multi-section landing page.
- Large diagonal metallic can occupies the central visual field, with real rendered highlights and unprinted aluminum rims/base.
- Locally hosted Lobster script restores the “Pure Zero” / “Refreshingly Clean” hierarchy.
- Frosted pill navigation, upper-right flavor cards, understated arrows, and compact lower-left signature follow the inspected reference.
- Flavor selection coordinates a full can spin, label swap, green/blue backdrop interpolation, mild transition blur, and cherry/blueberry swap.
- Cherries have shaped geometry, curved stems, surface texture, and specular highlights. Blueberries use non-periodic spherical noise, powder-like mottling, and a small calyx. Leaves have curved geometry and vein textures.
- Cards use thumbnails rendered from the same reconstructed 3D can—not crops of the reference video.
- Pointer spring response, local fruit repulsion, drifting bubbles, explicit pause, reduced motion, and WebGL/no-JavaScript fallback.

## Actual reference acquisition

The original MP4 did not need to be uploaded by the user. A narrowly scoped GitHub Actions research job fetched the public source video on a remote runner, extracted JPEGs with FFmpeg, and returned them through API-readable check outputs. A local script verified each image's SHA-256 before saving it for inspection.

- Actual duration: **7.433333 seconds**.
- Master size: **12,972,917 bytes**.
- Inspected images: poster plus six preview frames and six master frames.
- Master sample times: **0.00, 1.34, 2.68, 4.01, 5.35, 6.69 seconds**.
- Capture commit: `36ae0822c43116b003886592852c6992471b9cc0`.

The 2.68 s frame shows a spinning/blurred blue can over a still-green backdrop. By 4.01 s, the world is blue and cherries have changed to blueberries. This is actual visual evidence for a staged coordinated transition, not an assumption from the archived prose.

To restore the ignored local research frames after a workspace reset:

```sh
python3 getlayersai/tools/retrieve-reference.py 36ae0822c43116b003886592852c6992471b9cc0
```

Subsequent remote capture jobs require a commit message containing `[capture-reference]` as well as a change to the capture script/workflow on the research branch. Ordinary preview changes do not re-fetch the footage.

The images are research material, not runtime assets. They are not embedded in the website or copied to Pages. API retrieval works without asking the user to convert a video into an accepted upload format.

## Functional details and boundaries

- Diet Classic / Zero Lime names and $2.99 values match the visible reference.
- The source's unusual Zero Lime / blueberry association is preserved rather than renamed.
- Quantity and bag behavior are local simulations; no transaction, storage, or payment endpoint.
- Contact submissions validate sample inputs and explicitly state that nothing was sent or saved.
- The video does not open Ingredients, Eco, or Reviews. These buttons open explanatory local sheets; those sheets are not claimed to reproduce unseen source pages.
- The source's award footer is replaced with “Design study / Reference-led rebuild” to avoid inventing an award claim.

## Honest fidelity limits

The layout, typography direction, palette, product scale, and visible interaction sequence follow inspected frames. The product geometry, artwork, environment map, cherry/blueberry materials, and fallback are reconstructed; they are **not the original proprietary model or textures**. In particular, label lettering/emblem and fruit microstructure are not exact asset matches. No numerical pixel-parity score is claimed.

Only a desktop reference was available. Mobile is a deliberate responsive adaptation, not a claimed reconstruction of an unseen mobile original. The first implementation's technical pass did not establish visual success; this version must be judged against the original frames and by the user.
