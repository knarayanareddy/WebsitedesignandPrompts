From prompt to page.

Human imagination. New dimensions. An independent static interpretation of the archived GetLayers brief.

01 / Read the brief

The text source is 06-AI-STUDIO-CINEMATIC.md. Reference media could not be inspected in this environment. This is not a pixel-identical reconstruction.

02 / Establish a visual system

Background #100c18, foreground #faf6ff, accent #d2b4ff, surface #1c1627. Local fonts, a responsive 1320 px maximum grid, and a site-specific hero composition establish the hierarchy.

03 / Build the signature mechanism

A bevelled eight-point extruded star uses a procedural striped environment cube map for chrome reflections. A slow scroll-aware rotation and violet rim lights create depth. Local project dialogs and pipeline buttons present complete, fictional case-study briefs.

04 / Make it interactive

  • Open each project dialog and close with Escape
  • Switch all three pipeline stages and inspect the explanation
  • Inspect star reflections and reduced-motion behavior

05 / Record the adaptations

No stock films, neural rendering backend, sound generation, or scroll hijacking. Abstract CSS project plates replace unavailable campaign videos. No autoplay audio.

Shared architecture: local Three.js, native scrolling, a single frame scheduler, capped pixel density, offscreen/hidden-tab suspension, reduced-motion support, CSS fallback, and no backend.

06 / Validate honestly

See the actual validation record for test results. Automated checks do not replace manual screen-reader testing or reference-image comparison. All readouts and submissions are illustrative and local.
