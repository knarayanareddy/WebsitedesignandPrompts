LAOCOÖN
From prompt to page.

Form, tension, and the space between. An independent static interpretation of the archived GetLayers brief.

01 / Read the brief

The text source is 12-LAOCOON-WEBGL-SCULPTURE.md. Reference media could not be inspected in this environment. This is not a pixel-identical reconstruction.

02 / Establish a visual system

Background #0d0a08, foreground #f1e5d2, accent #dbb377, surface #1c1510. Local fonts, a responsive 1320 px maximum grid, and a site-specific hero composition establish the hierarchy.

03 / Build the signature mechanism

A central articulated figure, two smaller figures, plinth, and intertwined tube-curve serpents are assembled from original primitives. Scroll and a keyboard-accessible orbit button turn the group; light and material controls modify the same scene without reload.

04 / Make it interactive

  • Switch Bronze, Sapphire, and Stone
  • Adjust light temperature to both extremes
  • Orbit with the button and inspect output; scroll also rotates the composition

05 / Record the adaptations

An abstract procedural sculpture, not an archaeological scan or anatomically faithful replica. No museum affiliation, audio ambience, volumetric forge simulation, or projected anatomical labels. The source explicitly allowed procedural geometry.

Shared architecture: local Three.js, native scrolling, a single frame scheduler, capped pixel density, offscreen/hidden-tab suspension, reduced-motion support, CSS fallback, and no backend.

06 / Validate honestly

See the actual validation record for test results. Automated checks do not replace manual screen-reader testing or reference-image comparison. All readouts and submissions are illustrative and local.
